# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for a security problem.

Report it privately through GitHub: on the repository's **Security** tab,
choose **Report a vulnerability**. That opens a private advisory only the
maintainers can see. Include the affected version or commit, what an
attacker can do, and the steps to reproduce.

We aim to acknowledge a report within 3 working days and to agree a fix
and disclosure date with you. The default embargo is 90 days from the
report, or until a fixed release ships, whichever is sooner.

Issues in the underlying [rustango](https://github.com/ujeenet/rustango)
framework should be reported to that repository the same way; if you are
unsure which one a problem belongs to, report it here.

## Supported versions

rustango-cms is pre-1.0. Security fixes land on `main` and in the next
release; only the latest release is supported.
